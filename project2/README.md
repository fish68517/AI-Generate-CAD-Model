# project2：CAD-Coder 本地职责复现

本目录实现论文 `2505.14646v1` 图4、图5复现中不依赖13B模型的本地部分：

- 固定并下载官方100样本中的5个代表样本；
- 保存图片、Ground Truth CadQuery和STEP的SHA256清单；
- 对CadQuery代码进行静态安全检查、限时执行并导出STEP/STL；
- 复现论文的实体主轴对齐 `IOUbest`，完成自比较验证；
- 生成Ground Truth预览、图4四行骨架和图5圆角骨架；
- 生成一个可执行的圆角Oracle，用于证明圆角执行和检测链路正确；
- 为后续云端返回的模型代码预留统一结果接口。

本机不会加载或训练官方13B VLM。完整操作见 [`复现操作步骤.md`](./复现操作步骤.md)。
