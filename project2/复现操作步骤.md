# CAD-Coder 图4、图5本地职责复现操作步骤

## 1. 本文档对应的复现范围

本目录只执行本机能够可靠完成的部分：

```text
固定官方100样本
        ↓
确定性选择5个代表样本
        ↓
下载渲染图、Ground Truth CadQuery和STEP
        ↓
静态安全检查并执行CadQuery
        ↓
导出STEP/STL、计算IOUbest、渲染预览
        ↓
验证圆角Oracle
        ↓
生成图4/图5本地骨架
```

本机不加载官方13B模型，也不把Oracle结果称为模型预测。云端模型推理完成后，可以把模型回答带回本机，继续执行代码、计算IOU并生成正式图表。

## 3. 最简单的一键运行方法

打开 PowerShell，执行：

```powershell
cd E:\code\论文复现\project2
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_local_pipeline.ps1
```

脚本会依次完成：

1. 建立 `project2/.venv`；
2. 安装 CadQuery、NumPy、Matplotlib、Pillow、Requests 和 Pytest；

4. 下载官方固定数据；
5. 执行5条Ground Truth CadQuery；
6. 导出 STEP、STL；

11. 验证圆角前后几何变化；
12. 生成图4、图5骨架；

第一次安装后，如果只想重跑、不重复安装依赖和下载数据：

```

```

这证明本机 CadQuery、圆角、STEP/STL、检测和渲染链路工作正常，但不代表任何模型已经学会圆角。

### 5.2 为什么 `code_vs_official` 不一定等于1

`reports/local_pipeline_summary.json` 还记录了：

```text
iou_code_vs_official
```

该值比较“重新执行公开Ground Truth代码得到的STEP”和“仓库提供的官方STEP”。部分复杂样本会低于1，当前5条最低约为 `0.2346`。这不是模型分数，主要用于暴露以下一致性问题：

- 论文式主轴对齐在立方体等惯性特征值退化形状上存在轴选择歧义；
- 公开STEP和重新执行代码可能由不同 CadQuery/OCP 版本生成；
- 布尔并集、圆弧离散和双向拉伸可能产生版本相关差异；
- 公开资产中的CadQuery代码与STEP配对仍需作为实验变量审计。

因此，本地指标实现的首要验收是 `official STEP vs itself ≈ 1`。`code_vs_official` 应保留并解释，不能悄悄删掉，也不能当成模型预测质量。

## 8. 云端模型结果回传后的本机处理

云端每条结果保存成JSONL，格式示例：

```json
{"case_id":"f4_01","input_domain":"rendered","model":"CADCODER/CAD-Coder","revision":"具体revision","generation":{"temperature":0,"max_new_tokens":3450},"response":"```python\nimport cadquery as cq\n...\nsolid = solid0\n```"}
```

允许的 `input_domain`：

```text
real
rendered
```

把文件保存为：

```text
data/gpu_results/figure4_gpu_results.jsonl
```

然后执行：

```powershell
.\.venv\Scripts\python.exe .\scripts\process_figure4_gpu_results.py `
  --input .\data\gpu_results\figure4_gpu_results.jsonl
```

该脚本会：

1. 检查 `case_id`、输入域和重复记录；
2. 从模型回答中提取 CadQuery Python；
3. 执行静态安全检查；
4. 限时执行并导出 STEP/STL；
5. 与对应 Ground Truth STEP 计算论文式 `IOUbest`；
6. 生成预测预览；
7. 写入 `manifests/figure4_results.jsonl`。

生成正式图4：

```powershell
.\.venv\Scripts\python.exe .\scripts\render_figure4_grid.py `
  --results .\manifests\figure4_results.jsonl `
  --output .\reports\figure4_like\figure4_completed.png
```

## 10. 安全边界

`safe_execute_cadquery.py` 实现了：

- 只允许 `cadquery` 和 `math` import；
- 拒绝 `os`、`subprocess`、`open`、`eval`、`exec`、`__import__` 等；
- 拒绝双下划线属性访问；
- 要求最终变量 `solid`；
- 使用隔离Python进程；
- 设置超时；
- 保存stdout、stderr、退出码和文件hash。

但是，AST检查和Windows子进程不是完整安全沙箱。当前本机未安装Docker，因此本次只执行了官方已公开Ground Truth代码和本地生成的Oracle。

对未知模型输出，建议：

1. 先执行 `--validate-only`；
2. 人工检查代码；
3. 正式批处理时放入无网络、只读根文件系统、非root、限制CPU/内存/时间的一次性容器；
4. 不在包含密码、SSH密钥或重要资料的宿主环境直接执行未知Python。

## 11. 常见问题

### 11.1 PowerShell禁止执行脚本

使用：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run_local_pipeline.ps1
```

### 11.2 CadQuery安装失败

确认：

```powershell
py -3.12 --version
.\.venv\Scripts\python.exe -m pip --version
```

删除失败环境前先确认目标确实是：

```text
E:\code\论文复现\project2\.venv
```

然后重新建立。不要删除根目录的 CADmium `.venv`。

### 11.3 下载失败

重新运行：

```powershell
.\.venv\Scripts\python.exe .\scripts\prepare_official_subset.py --force
```

如果网络暂时不可用，保留已有 `data/source_manifest.json`，不要用空文件覆盖。

### 11.4 圆角失败

圆角半径必须小于局部几何尺寸。默认 `0.01` 已在 `f4_01` 立方体上验证。换案例时应先减小半径，并保存失败原因。

### 11.5 图中出现PENDING

这是正常状态，说明对应真实照片或GPU模型结果尚未提供。占位符是为了防止把未运行的模型结果误当成已完成实验。
